# Heritage image assets

The application displays real heritage photographs from Wikimedia Commons for the cards and details pages.
The PNG files in this folder are local fallback assets so the UI never becomes blank if an external photo is unavailable.

Real photo sources used by the app:
- Taj Mahal — Wikimedia Commons, The Taj Mahal, Agra
- Red Fort — Wikimedia Commons, Red fort Delhi
- Konark Sun Temple — Wikimedia Commons, KONARK SUN Temple
- Khajuraho — Wikimedia Commons, Khajuraho Temples, MP
- Hawa Mahal — Wikimedia Commons, HawaMahal.jpg
- Golden Temple — Wikimedia Commons, The Golden Temple in Amritsar
- Diwali — Wikimedia Commons, Diwali Diyas
- Bharatanatyam — Wikimedia Commons, A Bharatanatyam dancer

Check each Wikimedia Commons file page for its author and license before publishing the project publicly, and retain attribution where required.
