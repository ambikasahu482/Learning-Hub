# Heritage Learning Hub

A responsive React + Vite frontend for exploring Indian heritage through connected learning.

## Features

- Responsive navbar and mobile navigation
- Register/Login/Logout with localStorage
- Search and category filtering
- Heritage details and favorites
- Personalized interest + level assessment
- Connected learning roadmap
- Interactive topic quizzes with score calculation
- Progress persistence
- Learning resources
- Dashboard
- Certificate unlock at 80% progress
- Contact form validation
- Responsive desktop/tablet/mobile UI
- Framer Motion animations
- No NotFound page required for the defined application routes

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Deployment

This is a Vite SPA. For Netlify, use:
- Build command: `npm run build`
- Publish directory: `dist`

For a production deployment, configure SPA redirects so direct navigation to client routes serves `index.html`.
